# 卡期 · 智能用卡助手 v1.1.4

- 网站：<https://baimulinv.github.io/kaqi-card/>
- 源码：<https://github.com/baimulinv/kaqi-card>
- 推送接口：<https://kaqi-notify.pages.dev/api/config>（保留原接口作为备用）

## 开启手机通知

1. iPhone 使用 iOS 16.4 或以上版本，在 Safari 打开网站，点“分享 → 添加到主屏幕”。
2. 从主屏幕的“卡期”图标进入，打开设置。
3. 应用自动检测可用接口；后台连接正常时显示“待开启”，点击“开启手机推送”，在手机系统提示中选择“允许”。每台设备都需要各自授权。
4. 点击“测试手机通知”，到通知中心检查是否收到。后台接受发送请求并不等于手机已收到。

声音取决于手机通知、静音和专注模式设置，网站不能强制响铃。其他支持 Web Push 的浏览器可在 HTTPS 网站中允许通知。

## 提醒规则

- 北京时间：预计还款日前3天、前1天和当天，上午9点起发送；通道暂时失败在上午窗口内重试。
- 同一设备同一天的提醒合并成一条，避免重复打扰。
- 修改日期、删除卡片、导入备份、标记已还款之后，需要联网同步新的提醒日期。设置若显示“待同步”，请重新联网并打开应用核对。
- 已经送到通知中心的提醒不能远程撤回。手机日历中先前导入的 ICS 事件也不会因“已还款”自动删除。
- 长期不打开应用、清理浏览器数据、卸载主屏幕应用或更换设备后，请重新检查通知授权和备份。

## 数据保存

信用卡资料和还款记录保存在当前设备浏览器的 localStorage 中，没有账号云同步。请定期导出备份；换设备或清理浏览器数据前先备份。

开启推送后，仅将提醒日期、日期数量和设备推送订阅存到你的 Cloudflare 后台；不上传银行名称、昵称、卡号尾号、可用额度或应还金额。推送内容不包含银行卡信息。不要在任何地方录入完整卡号、密码、安全码或短信验证码。

## 部署结构

- GitHub Pages 托管 HTML、CSS、JS、manifest、Service Worker 和图标。
- push-config.js 只保存公开的后台 URL。
- Cloudflare Worker 负责通知订阅和发送；D1 独立数据库保存必要提醒资料；Cron 按 UTC 触发，在北京时间上午发送。
- VAPID 私钥仅在本机受限文件和 Cloudflare Secret 中保存，绝不能上传 GitHub。
- 本机后台源码：/Users/baimulin/Desktop/Codex/编程/信用卡推送服务，其 README 记录部署、测试和更新方法。

更新前端时，把本目录网页文件放在仓库根目录，Pages 来源仍为 main 分支、/(root)。上传 ZIP 本身不会变成网站。后台程序需要单独部署，只有网页上线并不代表推送后台上线。

## 使用边界

本工具只做日期估算和辅助提醒，不连接银行，不读取账单，不执行还款。最终还款日、应还金额与是否还清以银行账单为准。

## 连接检测

手机网络可能无法访问某些默认服务域名。当前优先使用 kaqi-notify.pages.dev 入口，保留原 workers.dev 入口并行检测。两者都转到同一个推送服务，沿用同一组密钥和数据。若显示“连接未成功”，可点击“重新检测连接”；这表示当前网络请求失败，不表示程序未部署。

## 测试通知结果

测试按钮下方会持续显示发送结果：通道接受时显示供应商和HTTP状态；失败时保留原因。已开启只代表订阅状态，不表示本次测试已送达。发送采用高优先级，能否响铃仍由手机设置决定。程序更新使用带版本的脚本与刷新缓存请求，保留本机卡片资料。

## 最近还款与新消费

首页显示新消费对应的账单日与预计还款日；本期还款倒计时在底部“还款日程”中查看。例如2026年10月25日，账单10日、同月30日还款：最近一期10月30日还有5天；当天新消费预计11月10日出账单、11月30日还款，间隔36天。

固定还款日新增自动判断：取账单之后最近的固定还款日期；保留人工指定当月/次月的规则。表单显示日期预览。旧记录若设为账单次月且还款日在账单日之后，会显示月份核对入口，用户核对后保存；不静默改写已有卡片、还款确认或日期校正。
